# Notes from the workbench & margin

A quiet corner of the internet for circuits, essays, half-finished thoughts, notebooks, strange ideas, and the occasional late-night obsession.

Built with **Next.js**, styled with an obsession for typography and atmosphere, and held together by too much coffee and `blur()`.

---

## About

This blog is where I document things I’m building, reading, learning, and thinking about.

Some posts are technical:

- electronics
- embedded systems
- markets
- software
- hardware experiments

Others are slower and more reflective:

- essays
- reading notes
- fragments
- observations
- dispatches from university life

The goal was to create something that feels less like a “content platform” and more like a personal notebook left open on a desk.

---

## Stack

- **Next.js**
- **React**
- **Tailwind CSS**
- **Motion**
- **MDX**
- Custom typography + motion system

---

## Features

- Minimal editorial design
- Cinematic page transitions
- Soft atmospheric hover effects
- MDX-powered posts
- Responsive layout
- Hand-tuned typography
- Dark mode by default because obviously

---

## Running locally

```bash
git clone <repo>
cd blog
npm install
npm run dev
```

Open `localhost:3000`.

---

## Structure

```txt
/app
/components
/content
/styles
/public
```

Posts live in the content directory and are rendered dynamically.

---

## Philosophy

I wanted the site to feel:

- warm
- quiet
- tactile
- slightly nostalgic
- like reading under a desk lamp at 1am

Fast, minimal, and deeply personal.

No feeds.
No growth hacks.
No engagement bait.

Just notes from the workbench & margin.
